# 盤面・初期化仕様 v1

> [設計ドキュメント索引](./designs/README.md) / [ルールブック](./designs/05-game-rules.md)

この文書は `RULE_VERSION = rules-1.0.0`、`MAP_VERSION = map-7x9-v1` の確定仕様である。座標はサーバ基準で、列を左から `A`〜`G`、行を北から `1`〜`9` とする。実装内部ではそれぞれ `x = 0..6`、`y = 0..8` を使う。

## 1. 固定領域

| 領域               | 座標   | 内容                 |
| ------------------ | ------ | -------------------- |
| 北側ゾーン         | A1〜G2 | Seat 1の初期配置領域 |
| ニュートラルゾーン | A3〜G7 | 生成地形を置く領域   |
| 南側ゾーン         | A8〜G9 | Seat 0の初期配置領域 |
| 北側の巣           | D1     | Seat 1の巣           |
| 南側の巣           | D9     | Seat 0の巣           |

北側・南側ゾーンの形と地形は固定で、巣以外はすべて通常マスとする。初期配置には各陣営13マスが使え、巣には配置できない。Seat 0から見た前方は北（行番号が減る方向）、Seat 1から見た前方は南（行番号が増える方向）である。

巣は占有・通常移動・噛みつきについて通常マスと同じで、敵も進入できる。1マス1体の制限も同じである。自軍の巣に捕虜を運んだ運搬役だけが捕食できる。

## 2. ニュートラルゾーン生成

生成器はUTF-8のseed文字列と `MAP_VERSION` を入力に、次を180度回転対称に配置する。

- 盤外マス：端に1組、計2マス。盤面輪郭を変化させる
- 木：2組、計4マス
- 沼：2組、計4マス
- その他：通常マス

B列とF列は全行を通常経路として予約し、盤外・木・沼を生成しない。候補はseedから決定論的にシャッフルする。候補が生成条件を満たさない場合、同じseedから導く試行番号を加えて次候補へ進み、最大64候補で失敗した場合は例外として試合を開始しない。

検証器は寸法、セルID、地形数、180度対称、全通行可能マスの連結、B/Fの通常経路、巣、各陣営8体分の配置領域を検証する。固定ゾーンが開けているため、巣の直前には常に複数の進入経路がある。

## 3. seed、先手、公開

- オンライン戦のseedはサーバが暗号学的乱数から32桁の16進文字列として試合ごとに生成する。
- ローカルCPU戦ではプレイヤーが1〜32文字のseedを指定できる。
- seed、`RULE_VERSION`、`MAP_VERSION`、先手は盤面生成後かつ布陣開始前に両者へ公開する。
- v1の先手は常に南側のSeat 0とする。先手初手を1活力にすることで補正する。
- 対局中には乱数を使わない。

## 4. 自動配置

ワニの処理順は、ヌシ、カツギ、ポチャ、ビヨーン、ナナメ、セッカチ、トビ、コワニとする。空きマスの処理順は前列を中央から左右交互、その後に後列を同順で処理する。

- 南側：D8, C8, E8, B8, F8, A8, G8, C9, E9, B9, F9, A9, G9
- 北側：D2, C2, E2, B2, F2, A2, G2, C1, E1, B1, F1, A1, G1

時間切れ時は最後の有効な手動配置を保持し、未配置のワニだけを上記のワニ順・空きマス順で補完する。

## 5. 確定した解釈

- セッカチワニの「直線」は前後左右のみで、斜めを含まない。
- 「巣へ近づく」は自軍巣までのマンハッタン距離が厳密に小さくなることをいう。
- ポチャワニの判定で「移動済み」に含むのは、通常移動、ジャンプ、沼退出、沼ワープ、通常噛みつきに伴う移動、運搬移動である。遠距離噛みつきは含まない。
- 同一局面キーには現在手番、残り活力、両者の得点と連続時間切れ数、全ワニの位置・捕虜関係・除外状態・ターン内移動／運搬／ジャンプ済みフラグを含む。ラウンド番号、通算ターン番号、時計の残秒は含めない。
