# ゲーム基本ルール

> [設計ドキュメント索引](./README.md)

企画書「8. 基本ルール案」「36. 今後の決定事項」をここで確定する。バランス値はプロトタイプ検証後に調整するが、**データ構造に影響する項目は本章で固定**する。

### 7.1 盤面：3レーン縄張り制（D-06）

```
                相手リーダー  HP 20 / 活力 3-3
       ┌──────────┬──────────┬──────────┐
縄張り  │  深い沼   │   中州    │   岩場    │  ← 各レーンに1枚（両者共有）
       ├──────────┼──────────┼──────────┤
相手陣  │ [ワニ][ワニ] │  [ワニ]   │          │  ← 各レーン最大3スロット
       ├──────────┼──────────┼──────────┤
自陣    │  [ワニ]   │ [ワニ][ワニ] │  [ワニ]  │
       └──────────┴──────────┴──────────┘
                     手札（扇形）
                自リーダー  HP 20 / 活力 4-4
```

- レーン数 **3**（左＝沼／中＝川／右＝陸 のイメージ）。各プレイヤーの各レーンのスロット数 **3**（盤面上限 9体）。
- ワニは配置時にレーンを指定する。**レーン間の移動は MVP では不可**（将来「移動」行動として追加）。
- 攻撃対象は **同一レーンの相手ワニのみ**。同レーンに相手ワニが1体もいなければ、相手リーダーへ直接攻撃できる。ただし相手レーンに **守護**（7.7）を持つワニがいる場合、リーダーへの直接攻撃は不可で守護ワニを優先対象にしなければならない。
- 縄張りカードは各レーンに1枚、両プレイヤー共有で常時効果を持つ。**上書きは同名カードのみ不可**（同じ縄張りを重ねて延長はできない）。異なる縄張りでの上書きは可能で、上書き時は前の効果を即座に失効させる。
- 環境カードは **有効期間内は同時に1枚のみ**（盤面全体1種／レーンごとに1種）。新しい環境カードを使用すると、同じスコープの既存の環境カードは即座に失効し墓地へ送られる（企画書の「増水」「干ばつ」等は同時両立しない前提）。

この盤面により、企画書 9章の「縄張りワニ（地形強化）」「群れ（同レーン強化）」「待ち伏せ」がそのまま成立し、「どのレーンに投資するか」という読み合いが生まれる。

### 7.1a 戦闘・トリガーの確定仕様（reducer 実装に必須）

企画書のルール案は方向性のみを示すため、`applyCommand` を実装できる粒度まで以下を確定する。

| 論点 | 確定内容 |
|---|---|
| 召喚ターンの攻撃可否 | 不可。**突進**（7.7）を持つワニのみ配置したターンから攻撃できる |
| 1体の1ターン攻撃回数 | **1回**。追加攻撃を与える効果は「攻撃済みフラグをリセットする」個別カード効果として実装する |
| 反撃 | **なし**。攻撃側の攻撃力ぶんだけ防御側にダメージが入る一方向ダメージとする（防御側は反撃しない） |
| 同時ダメージ・同時破壊 | ダメージ適用は即座（同期的）。1回の `attack` 処理内で「ダメージ適用 → 破壊判定」を1トランザクションとして行う。複数体が同時にHP0になった場合は破壊順を **盤面インデックス順（レーン0→2、自陣スロット0→2）** で確定し、破壊トリガの発火順もこの順に従う |
| 複数トリガの解決順 | 同一タイミングで複数のトリガが誘発した場合、**アクティブプレイヤーのトリガ → 非アクティブプレイヤーのトリガ**の順、同プレイヤー内は **盤面インデックス順** で解決する（APNAP順） |
| トリガの無限ループ防止 | 1回の Command 処理で誘発できるトリガ連鎖は **最大16段**。超過した場合は残りのトリガを破棄し、`ruleWarning` イベントを記録する（サーバ内部の安全弁であり通常のカード設計では到達しない） |
| 手札上限 | **10枚**。ターン終了時に10枚を超えている場合、超過分をターン終了処理の一部として墓地へ送る（オーバードローはドロー自体を妨げない） |
| 環境・縄張りの重複 | 上記本文のとおり、環境は同スコープにつき常に1枚、縄張りはレーンにつき1枚（異なる縄張りへの上書きのみ可） |
| 両リーダー同時 HP 0 | **引き分け**（`end_reason = 'draw'`）とする |
| `timeout_streak` のリセット条件 | そのプレイヤーが **時間内に自発的な `endTurn` を送った時点**でリセットする。サーバによる自動 `endTurn`（`sys.turnTimeout`）はリセットしない |
| 25ターン上限の数え方 | **ラウンド数**（先攻・後攻それぞれ1回ずつ手番を終えるごとに1ラウンド）。すなわち最大でプレイヤー個別の手番は50回まで |

### 7.2 カード種別

| 種別 | 主な属性 | 盤面での扱い |
|---|---|---|
| ワニ | コスト / 攻撃 / 体力 / 種族 / 生息地 / 能力 / レアリティ | レーンに常駐 |
| 行動 | コスト / 対象条件 / 効果 | 使用後に墓地へ |
| 環境 | コスト / 効果範囲（全体 or レーン） / 持続ターン | 持続効果として盤面に残る |
| 縄張り | コスト / 地形タイプ / 常時効果 | レーンに常駐（上書き可） |

- 種族（例）: `イリエ` `ナイル` `メガネ` `ガビアル` `子ワニ`
- 生息地（例）: `沼` `川` `陸`
- レアリティ: `コモン` `レア` `エピック`（MVP では入手経路を分けず、演出差のみ）

### 7.3 資源：活力（D-08）

- 名称は **活力**（企画書 8.4 の候補から選定。ワニ以外のカードにも自然に適用できる汎用語であるため）。
- 各プレイヤーは「最大活力」と「現在活力」を持つ。
- **初期最大活力は 1。試合開始時点（マリガン直後、第1ターン開始前）で最大活力=1・現在活力=1にセットする。**
- ターン開始処理（7.4 の手順3）での「最大活力+1、現在活力を全回復」は **第2ターン以降にのみ適用**する（第1手番のプレイヤーは1から、第2手番のプレイヤーが最初のターン開始処理を受けた時点で2になる）。上限 **10**。
- 後攻プレイヤーは開始時に **「濁流」トークン** を1枚得る（コスト0、使用すると現在活力 +1。その試合中1回のみ）。これにより後攻の初手は実質2点分の活力を使える。

### 7.4 ターン進行（D-10 / D-11）

**試合開始**

1. 先攻をサーバの安全な乱数で決定する。
2. 各プレイヤーのデッキをサーバがシャッフルする（9.5 の PRNG）。
3. 初期手札：先攻 **3枚** / 後攻 **4枚**。後攻に「濁流」トークンを追加。
4. **マリガン**：各プレイヤーは初期手札から任意の枚数を選んで戻し、同数を引き直す（戻したカードは引き直し後にデッキへ戻してシャッフル）。1回のみ。制限時間 30秒。

**1ターンの流れ**

1. ターン開始（`turnStart`）
2. 持続効果の減算・失効処理
3. 最大活力 +1（**第1手番のプレイヤーの最初のターンのみスキップ**。7.3参照）、現在活力を全回復
4. カードを1枚ドロー（デッキが空なら **疲労ダメージ**：1回目1、2回目2… とリーダーHPが減る）
5. 「日光浴」等のターン開始トリガ解決
6. プレイヤーの行動フェーズ（任意順・任意回数）
   - `playCard`（ワニ／行動／環境／縄張り）
   - `attack`（ワニ → 同レーンの相手ワニ or 相手リーダー。1体1ターン1回、召喚ターンは突進持ちのみ可。7.1a参照）
7. ターン終了（`endTurn`）／手札10枚超過分を墓地へ／ターン終了トリガ解決
8. 相手ターンへ

**時間管理**

- 1ターン **90秒**。超過するとサーバが自動で `endTurn` を実行する。
- **3ターン連続**で時間切れになったプレイヤーは敗北（放置対策）。
- 試合全体の上限は **25ターン、または開始から20分**。到達時はリーダーHPが多い方の勝利、同値なら引き分け。

### 7.5 勝利条件（D-07）

MVP は理解しやすさを優先し、**相手リーダーHP（初期20）を0にする**方式に一本化する。

決着理由（`end_reason`）は次を区別して記録する。`hp_zero` / `concede` / `timeout` / `disconnect` / `turn_limit` / `draw` / `void`（無効試合）。

### 7.6 デッキ規定（D-09）

- デッキ枚数：**30枚固定**（未満・超過は保存不可）
- 同名カード上限：**3枚**
- 初期カード種類：**24種**（ワニ14 / 行動6 / 環境2 / 縄張り2）
- 初期配布：全アカウントに24種を各3枚配布（企画書 28.1「初期カード配布」）。MVP では入手要素を設けず、デッキ構築に集中させる（企画書 33「初期カード不足」対策）。
- デッキは1アカウントあたり最大 **20個**。デッキ名は最大 **24文字**。

### 7.7 キーワード能力（MVP 8種）

企画書 9章の戦術的特徴を、実装可能な最小セットに落とし込む。

| キーワード | 効果 | 対応する企画書の系統 |
|---|---|---|
| 潜水 | 配置したターンの間、相手の行動・攻撃の対象にならない | 潜水ワニ |
| 待ち伏せ | 相手が同レーンにワニを配置したとき、1回だけ先制攻撃する | 待ち伏せワニ |
| 噛みつき | 攻撃時、相手ワニの攻撃力を永続的に -1 する | 噛みつき |
| 日光浴 | 自ターン中に攻撃しなかった場合、次のターン開始時に +1/+1 | 日光浴ワニ |
| 群れ | 同レーンにいる他の味方ワニ1体につき攻撃力 +1 | 小型ワニ／群れ |
| 縄張り適応 | 同レーンの縄張りが指定の地形なら +1/+1 | 縄張りワニ |
| 突進 | 配置したターンから攻撃できる | 大型ワニ |
| 守護 | 同レーンにいる間、相手はそのレーンからリーダーを直接攻撃できない | 縄張り防衛 |

「子ワニ」は共通キーワードではなく、**特定の親ワニが場にいると成長する**というカード個別効果として実装する。
